# Place portfolio images here

The HTML files reference images using paths like:
  - images/projects/blue-angel-oracle-decks/cover.jpg
  - images/projects/zodiac-oracle-deck/cover.png
  - images/new-work/new-001.png
  - images/grid-extras/our-lady-mural.jpg
  - etc. (see HTML files for full list)

**Source:** Jessica's portfolio site repo at `solocosmo/jessica-portfolio`
on GitHub. Clone it and copy `public/images/` into this folder.

The folder structure under public/images/ matches exactly what the HTML
expects — projects/, new-work/, grid-extras/.
